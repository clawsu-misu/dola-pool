Dola 本地登录 · 导出 Cookie

点「开始登录」后这台电脑会弹出一个浏览器窗口，你在里面手动登录（Google / Apple / 手机号都行，滑块手拖）。登进去之后工具自动导出 Cookie 并复制到剪贴板。

登录用的代理（出口必须是日本 / 韩国）

把控制台 curl 的三段原样填进来，工具不再拼接。-x 后面是网关，-U 引号里冒号前是用户名、冒号后是密码。用户名里的地区请在控制台选 JP 或 KR，不要用 Rand。

白名单认的是这台电脑的公网 IP，不是代理的日本出口。检测到后点复制，粘到 1024 控制台的白名单里添加。

尚未检测

链接里 region 用 JP 或 KR。提出来的只有地址，工具会连上去认协议（这种节点是 SOCKS5，按 HTTP 去连会被直接断开），再探测出口，连不上就不打开浏览器。地址有粘性时间，请在到期前完成登录。

用本机号池里给这个账号名绑定的代理；没绑定就直连。


    

  


  

    
推送到服务器

    
用服务器面板的管理员账号导入刚导出的这个号，工具会等服务器导入和在线验证结束。不想直推：到服务器面板「＋ 批量添加 → Cookie 头文本」粘贴剪贴板里的内容。
